# Introduction
기존 연구들은 temporal 정보를 활용하여 occluded 상황에 대한 성능을 향상시켰지만, 이는 ego-centric한 환경에만 국한되며 자차가 이동함에 따른 전역적인 인식을 고려하지 않음
- PETR에서는 fixed BEV space에 temporal 정보를 align하여 max-pool을 통해 BEV feature를 생성하는데 max-pool은 false prediction을 제거하지 못함
- 정확한 ego pose를 가정함

NeMO는 readable, writable BEV feature grid map을 생성하여 coarse-to-fine 방식으로 spatial matching으로 샘플링하고 이를 통해 다른 timestep의 정보를 활용
- *Long-range local map이라고 표현하는데 global map이라고 봐도 될듯*

NuScens와 BDD100K에서 실험을 진행하였는데, BDD100K에는 Map annotation이 존재하지 않기에 이에 대한 annotation을 추가하여 BDD-Map을 제공

# Methodology
![alt text](/assets/images/posts_img/nemo/overall.png)
### Coarse-to-fine spatial matching
- 데이터셋에서 제공하는 ego pose를 기반으로 coarse-to-fine 방식으로 spatial matching을 진행
- Ego pose에 noise가 있을 수 있고, grid 기반의 BEV feature map에 따라 정확한 위치가 아닐 수 있음
- Ego pose를 기준으로 Coarse하게 위치를 잡고 fine하게 local-spatial attention을 통해 low computational cost로 fine locational matching
    - *Hist BEV feature grid를 쿼리, 해당 grid 인근의 Cur BEV feature grid를 k, v로 하는 attention (convolution처럼 하는듯)*

### HomoGridFusion
- Coarse-to-fine spatial matching을 통해 매칭된 Hist BEV feature와 Cur BEV feature의 각 grid는 동일한 위치 정보를 포함하고 있음
- 각 grid에 대해 Hist BEV feature를 hidden state, Cur BEV feature를 새로운 feature로 취급하여 recurrent 모델로 융합
